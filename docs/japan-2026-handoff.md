너는 제니퍼소프트 홍재석(R&D팀 Frontend Tech Lead)의 일본 행사 발표 덱을 이어서 다듬는다. 발표는 일본어 슬라이드 + 한국어 보조 줄, 한국어로 말하고 통역자(제니퍼를 잘 아는 엔지니어)가 동시통역한다. 발표자는 발표 울렁증이 있어서, 대본을 보면서 읽는다.

## 저장소와 작업 규칙
- 저장소: github.com/jennifersoft/jennifer-ai-showcase (Next.js, Vercel 배포 https://jennifer.alvin.ing)
- 브랜치 없이 main에서 작업하고 바로 푸시한다. 커밋 작성자는 `alvin-hh <alvin@jennifersoft.com>` (Vercel이 이 작성자만 배포한다).
- 작업 전 항상 `git pull`. 다른 세션도 main에 푸시한다.
- 슬라이드: `slides/japan-2026/slides.html` (각 `<section>`의 `data-presenter`=발표자 대본, `data-script`=통역 원고(현재 발표자와 같은 문장), `data-notes`=노트), 스타일 `deck.css`, 연출 `deck.js`, 공통 엔진 `slides/_engine/`.
- 대본 페이지: /slides/japan-2026/script (발표자/통역 모드). 테스트: `npm test`.
- 대본은 **절대 임의로 줄이지 않는다.** 기존 문장을 두고 보완만 한다. (짧으면 발표자가 외워야 함)
- 용어: "트랜잭션/トランザクション"(거래·取引 금지), "연관 트랜잭션", "리뷰 요청"(MR 대신), "제니퍼소프트 GitHub".
- 한국어 보조 줄은 번역투 없이 자연스럽게, 발표자 1인칭("제가")으로.
- 색: 일본 사이트 보라 #7C73C2 + 무채색 검정 배경. 숫자·연도는 Montserrat, 한국어는 Pretendard.

## 현재 구성 (20장)
1 표지 AIと、JENNIFERの新しいつくり方 / 2 목차(3가지)
3~7 [01 開発は、AIと一緒に] AI 비서(ChatGPT '닷') 아침 브리핑 → 화면 QA(AI 비서가 브라우저로 직접 출시 전 X-View 콜트리 리뉴얼을 Figma 시안과 비교) → 에이전트 코딩 → 모바일 앱(영상은 발표자가 직접 만든 소개 영상: 대시보드·풀스크린 차트·X-View·제니퍼 인사이트)
8~15 [02 必要な連携を、AIですぐに実装] 질문 → 확장 역사 → PagerDuty 어댑터(일본 고객사 1곳 요청, 2026-02-03 약 1시간 20분에 구현·제니퍼소프트 GitHub 공개, 인시던트 화면은 재현) → 스킬(jennifer-extension) → 응용: PagerDuty 위젯(샘플 데이터, 사용자정의 대시보드 iframe)
16~18 [03 JENNIFERのデータをAIで活用] MCP 설명(LLM 서버=제니퍼 인사이트 서버에 포함, 뷰서버 Open API를 AI가 쓰기 쉽게) → 실례: ChatGPT+jennifer5-mcp 대시보드(Open API로 실시간 갱신)
19 仕事の進め方が変わった。(이전: 하나씩+대기 / 지금: 병렬, 영상·디자인 직접, 남은 시간=新しい挑戦) + 의심→두려움→희망
20 もっと多くのことに、挑戦できる時代へ。

## 사실 확인 포인트
- PagerDuty는 유료라 위젯은 샘플 데이터(API 형식 동일), 인시던트 화면은 어댑터 데이터로 재현. 대본에 "샘플" 언급 유지.
- 고객사 이름은 말하지 않는다. 클라라(k8s 프로젝트) 이름도 쓰지 않는다.
- 어댑터는 제품 버전 업그레이드 없이 추가된다("다음 버전" 표현 금지).
- 스킬·MCP는 ChatGPT 전용이 아니다(예시만 ChatGPT).
