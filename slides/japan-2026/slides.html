Figma 시안과 비교해서 다른 점 2가지를 찾았어.
  1. 짧은 막대가 사라짐: 1초 범위·차트 폭 300px에서 1ms 메서드가 0px로 계산돼. 최소 표시 폭과 클릭 영역을 보장하는 게 좋아.
  2. 데이터 누락 안내가 안 보임: 핀 1,000개 제한·시각 미확정·부분 수집 정보가 구현 화면에 안 보여.

제니퍼에는 이벤트 알림 어댑터, 고객사에 맞춘 사용자 인증 어댑터 등 여러 종류의 어댑터가 있습니다. 예전에는 개발 가이드를 보고 직접 구현했지만, 이제는 이 스킬을 넣은 AI 도구에 말로 요청하면 AI가 구현해 줍니다.

JENNIFERのデータを
AIで活用

AIツールを使えば、JENNIFERのOpen APIのデータで統計を確認したり、レポートをつくったり、さまざまな作業ができます。

AI 도구를 이용하면 제니퍼 Open API 데이터로 통계를 확인하고 보고서를 만드는 등 다양한 작업을 할 수 있습니다.

JENNIFERのデータをAIツールにつなぐJENNIFER MCP

JENNIFER MCPは、AIツールがJENNIFERのOpen APIのデータを簡単に活用できるようにする橋渡し役です。JENNIFER インサイトと同じLLMサーバーで提供します。

제니퍼 MCP는 AI 도구가 제니퍼 Open API 데이터를 쉽게 활용하도록 이어 주는 통로입니다. 제니퍼 인사이트와 같은 LLM 서버에서 제공합니다.
