📰 [아침 뉴스 · 10/13]

  1. Uber의 MCP 운영 설계
    도구별 권한·민감정보 제거·검색을 중앙에서 관리하고 새 도구는 검토 후 활성화하는 구조를 공개했어. WorkHub MCP 확장 시 API 재작성보다 권한·노출 관리를 먼저 정리하는 참고 사례야.
  2. 처리량이 좋아져도 실시간 품질은 나빠질 수 있음
    Campfire 재작성 분석에서 이벤트 버퍼를 늘리자 전달률은 개선됐지만 최대 지연도 크게 늘었어. JENNIFER 실시간 화면은 처리량뿐 아니라 전달 지연·유실·재접속 복구까지 검증해야 한다는 사례야.
  3. jevgrep: 자연어로 코드 위치 찾기
    동작 설명으로 관련 파일·줄 번호·코드 발췌를 찾는 CLI야. 검색 소스가 외부 AI 제공자로 전송되므로 사내 코드 적용 전 전송 범위를 확인해야 해.

📰［朝のニュース · 10/13］

  1. UberのMCP運用設計
    ツールごとの権限・機密情報の除去・検索を一元管理し、新しいツールはレビュー後に有効化する構成を公開。WorkHub MCP 拡張では、API の作り直しより権限・公開範囲の整理を先にする参考事例。
  2. スループットが上がっても、リアルタイム品質は下がることがある
    Campfire の再実装分析で、イベントバッファを増やすと到達率は改善したが最大遅延も大きく増えた。JENNIFER のリアルタイム画面は、スループットだけでなく到達遅延・欠損・再接続の復旧まで検証すべきという事例。
  3. jevgrep：自然言語でコードの場所を探す
    動作の説明から関連ファイル・行番号・コード抜粋を探す CLI。検索ソースが外部 AI プロバイダーに送られるため、社内コードに使う前に送信範囲の確認が必要。

AI秘書のPCで、画面QA

AI 비서가 자기 컴퓨터의 브라우저로 제니퍼 화면을 직접 열어 QA합니다. 클라라 대비 개선점과 캡처까지 정리해 줍니다.

今日 午前 7:52
너 컴퓨터에서 다시 콜트리 qa 진행하고 리뷰해줘.
君のPCで、もう一度コールツリーのQAをしてレビューして。
응. 내 클라우드 브라우저에서 한국어·라이트 테마로 다시 QA할게. 최신 화면 반영부터 확인하고, 핀·Link → 콜트리 선택 → 상세 이동과 높이·여백까지 리뷰해서 캡처와 함께 알려줄게.
了解。クラウドブラウザで韓国語・ライトテーマのままもう一度QAするね。最新の画面反映から確認して、ピン・Link → コールツリー選択 → 詳細への移動と、高さ・余白までレビューして、キャプチャと一緒に報告するよ。
그리고 개선할만한점 클라라 대비 더 강화할점등을 체크해봐
あと、Clara と比べて改善・強化できる点もチェックして。
클라라 코드 비교에서 우선 보완할 2가지를 찾았어.
  1. 짧은 막대가 사라짐: 1초 범위·차트 폭 300px에서 1ms 메서드가 0px로 계산돼. 최소 표시 폭과 클릭 영역을 보장하는 게 좋아.
  2. 데이터 누락 안내 부족: 핀 1,000개 제한·시각 미확정·부분 수집 정보가 일반 화면에 안 보여.
Clara のコード比較で、まず補うべき2点が見つかった。
  1. 短いバーが消える：1秒範囲・チャート幅300pxで、1msのメソッドが0pxになる。最小表示幅とクリック領域を保証したほうがいい。
  2. データ欠落の案内が不足：ピン1,000件の上限・時刻未確定・部分収集の情報が通常画面に出ない。
QA 진행 중이지?
QA、進んでる？
응. 재로그인 끝났고 내 클라우드 브라우저에서 JENNIFER DEMO 거래를 열어 확인 중이야. 지금은 실제 핀·Link 연동과 화면 높이·여백을 검증하고 있어.
うん。再ログインが終わって、クラウドブラウザで JENNIFER DEMO の取引を開いて確認中。今は実際のピン・Link 連動と画面の高さ・余白を検証してる。
실서버 QA 마쳤어. 핵심 UX는 정상 동작해.
  • 에러 핀·메서드·Link 클릭 → 콜트리 자동 펼침·행 선택만 수행
  • 콜트리 '호출함' → 상대 거래 상세 이동, 추가 중첩은 차단
  • 5행·여백·긴 이름 말줄임 정상, 1188px 화면에서 가로 넘침 없음
클라라 대비 강화 우선순위: ① 위치 미확정 스택·부분 수집·핀 표시 제한 안내 ② 짧은 막대의 최소 표시 폭·클릭 영역 ③ 연결 거래 진입 시 Call Tree 탭 유지
実サーバーのQA完了。主要なUXは正常に動作してる。
  • エラーピン・メソッド・Link をクリック → コールツリーの自動展開・行選択のみ
  • コールツリーの「呼び出し」→ 相手取引の詳細へ移動、さらなるネストは遮断
  • 5行・余白・長い名前の省略は正常、1188px 画面で横あふれなし
Clara と比べた強化の優先順位：① 位置未確定のスタック・部分収集・ピン表示上限の案内 ② 短いバーの最小表示幅・クリック領域 ③ 連携取引に入ったときの Call Tree タブ維持
